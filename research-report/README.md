# research-report

Turns synthesis output into a shareable findings document for stakeholders.

## What it does

Assembles context, method, and themes with quote evidence into report format (Automate), drafts a
readable narrative order across themes (Assist), and replaces a recommendations section with open
questions the team still needs to decide (Protect) — no verdict, no "what to build" baked into the
findings.

Consumes `synthesis` output. Can feed into `insight-card` for single shareable insights.

## Usage

`/research-report` with synthesized themes, or point it at synthesis output.

## Install

See the root [README](../README.md) — `./install.sh` for Claude Code, or upload
[`dist/research-report.zip`](../dist/research-report.zip) on Claude.ai.
